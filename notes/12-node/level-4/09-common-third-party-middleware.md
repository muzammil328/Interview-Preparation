| Middleware  | Purpose               |
| ----------- | --------------------- |
| cors        | Enable CORS           |
| helmet      | Secure HTTP headers   |
| morgan      | Logging               |
| multer      | File upload           |
| dotenv      | Environment variables (not middleware — a config loader) |
| body-parser | Request body parsing (built into Express 4.16+ as `express.json()` / `express.urlencoded()`) |
