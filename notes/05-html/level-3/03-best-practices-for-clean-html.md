- Use semantic elements.
- Maintain proper indentation.
- Use correct nesting.
- Add meaningful `alt` text.
- Use labels for forms.
- Avoid unnecessary wrappers.
- Follow heading hierarchy.
- Keep markup simple and readable.
- Validate HTML regularly.
